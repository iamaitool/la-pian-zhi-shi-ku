# 拉片知识库（独立静态版）

通过不断拉片，积累视听语言知识库；下次输入剧本，按知识库生成分镜和视频提示词。

## 功能

- **拉片库**：新增 / 编辑 / 删除镜头，字段包括景别、机位、构图、运镜、光线、画面内容、人物动作、情绪、对白、背景音乐、音效、转场方式、蒙太奇运用、为什么这样用，另有时间码、时长、关键帧缩略图；支持搜索、按情绪筛选；一键提炼到知识库。
- **视听语言知识库**：规律按情绪 / 场景类型 / 节奏分类，可搜索、打标签、新增 / 编辑 / 删除。
- **剧本转分镜**：粘贴剧本，选择情绪、场景类型、节奏，按本地知识库匹配生成分镜表，每镜含中英文视频提示词，可复制全部、导出 TXT。
- **视频导入**：上传本地视频文件，或粘贴可直接下载的视频文件链接；浏览器本地按画面变化切分镜头（灵敏度可调），预填开始时间码、时长、关键帧；超过 10 分钟会提示先用 5–10 分钟关键段落。草稿自动保存到 localStorage，切页签、刷新后仍在，中断后可断点恢复；批量存入拉片库后清除草稿。
- **识图预填**：单镜按钮与“批量识图前 10 个”。本独立版没有服务端 AI，预填是**本地像素启发式**（亮度 / 对比度 / 主色），只填景别近似、构图、光线、画面内容描述、情绪推测，并明确标注“本地启发式预填 / 推测”；运镜、转场、蒙太奇、对白、音乐音效、为什么这样用留空，不编造 AI 视觉结果。
- **顺序预填**：看前后镜头、镜头顺序和对白，用本地规则推测转场方式、蒙太奇运用和为什么这样用，标注“AI预填·推测”（本地规则）。
- **字幕识别**：优先上传 SRT 字幕文件（解析后按时间码对齐填对白，标注来源 SRT）；画面字幕 OCR 通过 Tesseract.js CDN 按需加载，需联网，若加载失败请改用 SRT 或手动填对白，不会谎称 OCR 可用。
- **悬停大图**：鼠标停在关键帧缩略图上弹出放大预览（镜头序号、时间码、时长），预览放在行下方 / 空白处，不遮住输入框；触屏点一下打开，再点空白处关闭。

## 运行

直接双击打开 `index.html` 即可；更稳妥的方式是静态托管：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

不需要安装依赖，不需要后端。画面字幕 OCR 需要联网加载 Tesseract.js CDN，其余功能可离线使用。

## 数据存储

所有数据（拉片、知识库、分镜历史、导入草稿）只存在本浏览器 `localStorage`（键 `lapian-standalone-v1`）中，不会上传。换浏览器 / 清除浏览器数据会丢失。示例数据（5 条拉片、5 条知识）带“示例”标记，可用“一键清空示例”删除，不会删你的数据。

## 与 Muse 托管版的区别

本仓库是独立静态复刻：数据用 localStorage 而不是服务端数据库；识图预填、顺序预填、剧本转分镜均为本地规则 / 启发式，不含 Muse 托管版的服务端模型调用；视频导入、字幕 SRT 解析、场景切分均为浏览器本地实现。
